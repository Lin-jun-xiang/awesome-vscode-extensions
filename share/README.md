### Scigantic

* Scigantic is a VS Code and Cursor extension that searches a catalog of public research datasets and mounts one as a read-only local folder. Files are fetched on demand, so nothing is downloaded first.

* The mount is a normal path, so it works from the editor, the terminal, Python and R. It runs rclone to mount public S3, GCS and Azure Blob buckets, Zenodo records and public HTTP file trees.

* It is free and MIT licensed. Tested on macOS and Linux. Windows support is untested.

* Dataset catalog: <https://scigantic.com/explore>

* VS Code Marketplace: <https://marketplace.visualstudio.com/items?itemName=scigantic.scigantic-mount>

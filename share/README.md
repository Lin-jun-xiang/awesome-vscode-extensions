## Sharing and Contributing by Community

* Anyone can share interesting and useful extensions in "**Discussions**"

* Anyone can post interesting and useful extensions in "`share/README.md`" via **Pull Requests**

### AudioLens

* [AudioLens](https://marketplace.visualstudio.com/items?itemName=simzhou.audiolens) lets you listen to audio and inspect waveforms and spectrograms inside VS Code.
* Each channel has its own track with mute/solo controls. Select a region to listen to it, inspect RMS, sample peak and clipping, or export the selection as WAV.
* Adjust FFT size, window function and frequency scale, or open a supported audio path from a text file using the hover action.
* Free and open source under Apache-2.0: [source and documentation](https://github.com/SimZhou/vscode-audiolens).
